プライバシーポリシー

最終更新：2026年10月21日

IPPUKU GAMES（以下「本サイト」）は、ブラウザだけで遊べるゲーム集です。会員登録や課金はなく、名前・メールアドレスなどの個人情報を入力していただくことはありません。

1. 端末に保存する情報

遊びやすくするため、次の情報をお使いのブラウザ（localStorage）に保存します。これらは端末の中だけにあり、本サイトの運営者を含め外部には送信しません。ブラウザのサイトデータを消すと削除されます。

保存する内容ページ
前回あそんだゲーム（hub.recent）入口
CPUの強さ・後手ボーナス（alcheroro.level ほか）AlcheRoro
CPUの人数・強さなどの設定（bustedup.settings）BUSTED UP!
CPUの強さ（nullhand.settings）NULL-HAND

また、ホーム画面に追加したときにオフラインでも遊べるよう、ページのファイルをブラウザに保存（キャッシュ）します。

2. アクセス解析・広告

現在、本サイトはアクセス解析ツールや広告を使っていません。導入する場合は、事前にこのページで内容をお知らせします。

3. 外部のサービス

  • GitHub Pages：本サイトは GitHub, Inc. のサービスで公開しています。ページを開くと、GitHub のサーバーにIPアドレスなどの接続情報が届きます。取り扱いは GitHub のプライバシーに関する声明によります。
  • Google Fonts：入口のページは文字の表示に Google Fonts を使っており、文字のデータを Google のサーバーから読み込みます。取り扱いは Google のプライバシーポリシーによります。

4. このページの変更

内容を変える場合は、このページを更新し、最終更新日を改めます。

5. お問い合わせ

本サイトに関するお問い合わせは、GitHub の Issues からお願いします。
